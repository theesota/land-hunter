# 土地スカウト

家づくりの土地探し用マップアプリ。歩きながら気になった土地をピンで保存し、ハザードマップを重ねて確認し、共有リンクで家族と同期できる。サーバー不要の静的アプリ。GitHub Pagesで https://theesota.github.io/land-hunter/ として公開する。

## できること

- **地点の保存**: 「＋」→地図タップで保存。名前・ステータス(気になる/見学済み/候補/見送り)・★評価・メモ付き。ピンの色はステータス連動
- **ハザードマップ重ね表示**: 洪水(想定最大規模)・土砂災害3種・津波・高潮を地図に重ねられる。濃さも調整可
- **現在地追跡**: 📍で歩きながら現在地を追従表示
- **Googleマップ連携**: 各ピンから「Googleマップで開く」(経路・ストリートビューへ)、「重ねるハザードマップで開く」(公式サイトの同地点)
- **共有**: 🔗から共有リンクを生成してLINE等で送る。開いた側は「取り込む」でマージされる(同じ地点は編集が新しい方が勝つ)。JSONファイルでのバックアップ/移行も可

## 公開手順(初回のみ)

1. GitHubのリポジトリ設定 → Pages
2. Source: `Deploy from a branch`、Branch: `main`、フォルダ: `/ (root)` → Save
3. 数分後に https://theesota.github.io/land-hunter/ で開ける
4. スマホでそのURLを開き「ホーム画面に追加」しておくとアプリっぽく使える

## データの持ち方と共有の仕組み

- 地点データは各端末のlocalStorageに保存(サーバーには何も送らない)
- 共有リンクは全地点をURLのハッシュ部分に埋め込む方式。リンクを開いて「取り込む」を押すとローカルにマージされる
- マージは地点ID単位で、`updatedAt`が新しい方を採用。二人で別々の地点を追加しても消し合わない
- 制約: リアルタイム同期ではない。「編集したらリンクを送る」運用。地点が100件を超えるあたりからURLが長くなるので、その場合はJSON書き出しで送る

## 技術構成

- 地図: [Leaflet](https://leafletjs.com/) + [地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)(淡色/航空写真)
- ハザード: [重ねるハザードマップのオープンデータ配信タイル](https://disaportal.gsi.go.jp/hazardmap/copyright/opendata.html)(国土交通省/国土地理院、ズーム2〜17)
- ビルド不要のES Modules構成:
  - `js/config.js` … タイルURL・ステータス定義(レイヤ追加はここだけ)
  - `js/store.js` … データモデル・localStorage・マージ
  - `js/share.js` … 共有リンクのエンコード/デコード・JSON入出力
  - `js/map.js` … Leafletラッパー(レイヤ・マーカー・現在地)
  - `js/app.js` … UI結線

## 拡張ポイント

- **リアルタイム同期**: FirebaseのFirestoreを足せばリンク送り合い不要になる。`store.js`の保存先を差し替えるだけで済む構造にしてある
- **写真添付**: localStorage容量の都合で未実装。同期バックエンド導入とセットでやるのが正解
- **地点ごとのハザード自動判定**: ハザードタイルのピクセル色を読んで「この地点は浸水3m想定」等を自動表示する拡張が可能
